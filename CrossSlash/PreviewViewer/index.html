World terrain view guide

Terrain type

Each triangle has a movement type. It affects where Cloud and vehicles can travel, and some types affect encounters or special behavior.

Regions

Region IDs mark world areas used for area behavior and encounter data. Gray means the current map has no color entry for that ID.

Scripts

Script values select behavior attached to a mesh triangle. Yellow triangles have the Chocobo encounter flag; this color takes priority over the script color.
